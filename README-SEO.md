### Step 1: Update HTML Files (10 minutes)

1. Open `SEO-IMPLEMENTATION-GUIDE.md`
2. Copy the `<head>` section for each page
3. Replace the existing `<head>` in your HTML files
4. Save and upload to your server

### Step 2: Upload SEO Files (3 minutes)

1. Upload `sitemap.xml` to website root
2. Upload `robots.txt` to website root
3. Upload `.htaccess` to website root (if Apache server)
4. Test: Visit https://patelmotor.in/sitemap.xml

### Step 3: Submit to Google (2 minutes)

1. Go to: https://search.google.com/search-console
2. Add your website
3. Submit sitemap
4. Request indexing
