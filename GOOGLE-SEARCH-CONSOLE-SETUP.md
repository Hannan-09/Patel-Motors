# Google Search Console Setup Guide for Patel Motors

## 🚀 Quick Start (15 Minutes Setup)

### Step 1: Verify Your Website

1. Go to: https://search.google.com/search-console
2. Click "Add Property"
3. Enter: `patelmotor.in`
4. Choose verification method:
   - **HTML File Upload** (Easiest)
   - Download the verification file
   - Upload to your website root folder
   - Click "Verify"

### Step 2: Submit Sitemap

1. In Search Console, go to "Sitemaps" (left menu)
2. Enter: `sitemap.xml`
3. Click "Submit"
4. Wait 24-48 hours for Google to crawl

### Step 3: Request Indexing

1. Go to "URL Inspection" tool
2. Enter each page URL:
   - https://patelmotor.in/
   - https://patelmotor.in/products.html
   - https://patelmotor.in/about.html
   - https://patelmotor.in/contact.html
   - https://patelmotor.in/catalogue.html
3. Click "Request Indexing" for each page

## 📊 Google Analytics Setup (Optional but Recommended)

### Step 1: Create Account

1. Go to: https://analytics.google.com
2. Click "Start measuring"
3. Enter account name: "Patel Motors"
4. Enter property name: "Patel Motors Website"
5. Select India as country

### Step 2: Get Tracking Code

1. Copy the tracking code (starts with G-XXXXXXXXXX)
2. Add this code to ALL your HTML pages, just before `</head>`:

```html
<!-- Google Analytics -->
<script
  async
  src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"
></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag() {
    dataLayer.push(arguments);
  }
  gtag("js", new Date());
  gtag("config", "G-XXXXXXXXXX");
</script>
```

## 🆘 Troubleshooting

### Website Not Showing in Google?

- Check if sitemap is submitted
- Request indexing manually
- Wait 48-72 hours
- Check robots.txt is not blocking

### Low Rankings?

- Add more content to pages
- Get more backlinks
- Improve page speed
- Add more product images with alt text

### No Traffic?

- Check Google Analytics is installed correctly
- Verify Search Console shows impressions
- Create more content
- Share on social media
